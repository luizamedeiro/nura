# Nura · The 28-Day Routine

Product detail page (PDP) for **Nura**, a fictional skincare brand for sun spots, created as a design study by By.Malu.

- Static site: HTML, CSS and vanilla JavaScript, no framework or build step.
- Responsive (desktop and mobile), with scroll-driven interactions: hero slideshow, card deck, color slider for the four steps, expanding ingredient panels and a before/after compare.
- Products, prices, reviews and results are illustrative.

To run locally, serve the folder with any static server, for example:

```bash
python3 -m http.server 8000
```
